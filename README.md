# ЛР по Python №3. Каталог библиотечных книг

Выполнил Сенаторов Алексей, М8О-103БВ-26

Пакет на Python 3.14 для хранения библиотечных книг. Их можно добавлять и удалять, искать по ID, названию и категории, сохранять в JSON, а также выгружать из него данные

## Книга и каталог

`Book` — класс книги. Он хранит (случайный) строковый ID, название, категорию, год написания, имя автора, количество страниц и язык, на котором была написана книга. При создании проверяются все поля, при ошибке поднимается исключение `IncorrectEntity`.

`Catalog` хранит книги в словаре. Так как ID для каждой книги сгенерирован при её создании через `uuid` шанс коллизий минимален, однако на всякий случай может подняться ошибка `IDDuplicate`. Поиск по названию работает без учёта регистра (по категории он строгий). При обходе каталога книги выдаются в порядке добавления.

## Работа с JSON

В корне файла находятся номер версии `format_version` и список книг `items`.

При загрузке маршруты сначала проверяются во временном каталоге. Если весь файл прочитан успешно, новые маршруты добавляются в основной каталог. При ошибке чтения или проверки файла основной каталог остаётся без изменений.

## Структура проекта

- `src/catalog/models.py` — класс `Book`
- `src/catalog/catalog.py` - класс `Catalog`
- `src/catalog/errors.py` — исключения каталога.
- `src/catalog/memory.py` — работа с JSON.
- `tests/` — тесты модели, каталога и работы с JSON.
